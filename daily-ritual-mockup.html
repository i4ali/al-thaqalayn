The Daily Ritual

One place where a user gathers anything in the app - a verse, a dua, a deep dive, a life moment, a puzzle - into a personal daily practice. They move through it each day, check items off, and the habit shows up on the Progress tab with its own streak and history.

Midnight Emerald, app default Gold #D6B25E accent Cormorant Garamond + Amiri, the app's own faces EmCard · EmIconChip · r20 · existing parts only
On naming: screens below say "Daily Ritual", which is clear and friendly. The classical term for exactly this practice is the wird وِرْد, a fixed daily portion of devotion. "My Wird" is a beautiful, rooted alternative if you want the app to teach the word.
01 · Discover it on Today

A card that behaves like the ones users already know

  • Placement: directly under the greeting, above the daily reminder hero. The ritual is the user's own commitment, so it opens the day; everything the app pushes (reminder, What's New, crossword) follows it.
  • Anatomy is DailyCrosswordCard's: EmIconChip 46, serif 20 title, gold caps sub-line with the 🔥 streak, chevron. One new element: a five-segment strip, one segment per ritual item, so progress is visible without opening.
  • States: "3 OF 5 · 🔥 12" while in progress; when everything is checked the sub-line flips to green "DONE FOR TODAY · 🔥 13" and the chevron becomes the green checkmark.circle.fill, exactly like the crossword card.
  • Empty state: before anything is added the card reads "Build your Daily Ritual · add anything from the app" and opens the picker in section 03 instead of the checklist.
02 · The daily checklist

Check off the day, watch the streak hold

Live mock, tap the rows to check them off
  • Every row is the same skeleton: EmCard, icon chip that turns gold when done, a small type eyebrow (QUR'AN, DUA, DEEP DIVE...), serif title, one meta line. The check circle on the right is the only toggle target.
  • Tapping the row body opens the content itself, routed exactly like today's cards: verses through the hidden NavigationLink, the crossword as a sheet, deep dives through DeepLinkRouter to the Journey tab. Opening and completing stay separate gestures.
  • Two kinds of completion: manual items (a verse, a dua) are checked by the user; items that already know when they're done (crossword solved, challenge answered, journey day completed) check themselves.
  • Rows keep the user's order, a litany has muscle memory. Edit mode gives drag handles, remove, and reorder.
  • All five checked brings up the gold completion moment and bumps the streak using the same dayKey transition the challenge and crossword streaks use. At midnight refreshForToday() clears the checks, like the crossword card.
  • Chrome only on this screen, so nothing here needs the reading text-size scale; the reading content lives in the detail views, which already scale.
03 · Building the ritual

One picker across the whole app

  • A single sheet lists every addable type, grouped under the existing gold section labels: Daily Duas, Life Moments, Deep Dives, Qur'an, Foods, Games, and so on. The + toggles instantly; no navigating away and back.
  • Anything with an id can be an item. The unit is RitualItem {type, refId}, where type covers verse, surah, dua, lifeMoment, deepDive, journeyDay, food, story, parallel, crossword, challenge. New content types join by adding an enum case.
  • Reached from three places: the Today card's empty state, the dashed "Add from the app" row, and Edit mode.
  • Premium suggestion: the ritual is free up to 3 items, unlimited with Premium. Signalled house-style, a gold Premium capsule and never a lock; tapping a fourth + routes to the paywall.
04 · Add from anywhere

Every detail view gets the same small chip

Tap "Add to Ritual" on the phone
  • One reusable component, RitualAddButton(item:), in the same capsule language as DuaListenButton, so the action row reads as one family. Listen keeps its place; every dua and ziyarat still leads with it.
  • It's a toggle: add flips it to the gold "In your Ritual" state; tapping again removes, with an undo toast rather than a confirm dialog.
  • The same chip drops into SurahDetailView's verse action row next to the bookmark heart, plus DeepDiveView, FoodDetailView, StoryDetailView, ParallelDetailView, and journey day screens.
  • Why both paths matter: the picker is for building deliberately; this chip captures the "I want this in my life daily" impulse at the moment it happens.
05 · Progress tab

The habit becomes a record

  • Slots after the streak card, before badges. The rings card and stats grid above are untouched (rings omitted in this frame for space).
  • The week strip is new information the app can't show today: gold check for a complete day, an open ring with 4/5 for a partial one, the glowing ring for today in progress. It needs the one genuinely new piece of storage, a dayKey → completed item ids map, the app's first per-day history.
  • Streak rule: a day counts when every item is checked, partial days show in the strip but don't extend the flame. Honest streaks keep the ritual meaningful.
  • Ring option: today's ritual completion can also join ProgressRingsStack as a fourth ring in the seasonal slot, gold on gold; worth an A/B later.
  • New badges suggest themselves: First Ritual, a 7-Day Wird, and a 40-Day Constancy badge, forty days being the tradition's own measure of a practice that sticks.
06 · If we build it

Everything reuses a pattern the codebase already trusts

Nothing here invents new visual language or navigation. One new manager, one new model, one new screen, one reusable chip.

Data model

RitualItem

  • RitualItem { id, type, refId, order, addedAt } with a snapshot title stored so rows survive content renames.
  • RitualItemType enum: verse, surah, dua, lifeMoment, deepDive, journeyDay, food, story, parallel, crossword, challenge.
  • Rendering resolves refId through the existing managers (DuasManager, DeepDiveCatalog, DataManager...).
State & streaks

DailyRitualManager

  • Mirrors DailyChallengeManager: same dayKey("yyyy-MM-dd"), same pure streak transition, same refreshForToday() on scenePhase.
  • Adds the app's first per-day history: [dayKey: Set<itemId>], powering the week strip and 30-day percent.
  • UserDefaults first, then Supabase sync following BookmarkManager's three-step pattern.
  • Auto-check hooks: crossword/challenge completion and journey markDayCompleted notify the ritual.
Surfaces & navigation

Four touchpoints

  • Today card → ritual screen via the existing hidden-NavigationLink pattern.
  • Row taps route with the mechanisms each type already uses, including DeepLinkRouter for cross-tab.
  • Picker sheet + RitualAddButton chip on detail views.
  • Progress card after the streak card; optional fourth ring.
Rollout

House rules honored

  • What's New entry in EN/UR/AR with a new WhatsNewDestination case (per CLAUDE.md, no em dash in copy).
  • Premium: 3 items free, unlimited with Premium; gold capsule, never a lock; PremiumManager.canAddRitualItem(count:) → PaywallView.
  • Reading scale: the ritual screen is chrome; content opens in detail views that already scale. Listen stays on every dua surface.
  • Ships in both themes; the mock shows Midnight Emerald, the light variant follows the legacy card recipe.
